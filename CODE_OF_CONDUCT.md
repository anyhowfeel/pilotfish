# Code of conduct

Be respectful and constructive. Criticise code and ideas, not people. Harassment,
personal attacks and discriminatory language are not accepted in issues, pull requests or
discussions.

Maintainers may edit or remove comments, and close or lock threads, that go against this.
To report a problem, use the private reporting described in `SECURITY.md` or open a
minimal issue asking for a maintainer to get in touch.

This is a small project and this text is intentionally short.
